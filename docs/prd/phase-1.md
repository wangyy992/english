## 任務 1.2 今日時長規劃器

- 「今日」頁當日首次進入顯示單屏零彈窗時長選擇:30min / 1h / 2h / 3h + 自定義;記住上次選擇為默認,一次點擊開始。
- 按權重分配到五模組,生成帶目標時長的任務卡:
  - 默認權重:聽 30 / 說 20 / 讀 20 / 寫 15 / 詞彙 15(%);存 storage,設定頁可調(Phase 3 改動態,本 Phase 靜態)
  - 詞彙→卡片數(6 秒/卡,與到期數取小);聽力→集數(按素材實際時長);寫作 <30min 只出中譯英,≥30min 出自由寫作
- 任務卡內建計時:進入模組自動計時,離開暫停;達標時長或完成條件即標記完成。
- 完成驗證混合制:
  - 硬驗證:聽力(實際播放時長)、詞彙(到期清空)、寫作(提交批改)、跟讀(有錄音)
  - 自報:泛聽、閱讀(「我讀完了」按鈕 + 記錄停留時長)
- 未完成部分次日以「昨日欠账」置頂提示(不強制,獎懲留 Phase 3)。
- streak 升級:當日完成 ≥ 70% 分配任務才算打卡(替代「做任何一項就算」)。
