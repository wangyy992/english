# Phase 3 — 家教大腦:能力模型 + 動態規劃 + 獎懲 + 口語對話

> 先讀 `docs/prd/README.md`。前置:Phase 2 已驗收。按 3.1→3.4 順序。

## 任務 3.1 能力模型

- `src/lib/ability.ts`:五維分數 listening / speaking / reading / writing / vocab,各 0-100,存 storage。
- 更新規則:EWMA,α=0.3,每次活動後更新對應維度:
  - listening:精聽自評 + 跟讀平均分
  - speaking:跟讀/復述/對話的發音分與內容分
  - reading:閱讀量 + 文章生詞密度(查詞次數/詞數,越低分越高)
  - writing:批改 rubric 分數歸一化
  - vocab:FSRS 留存率(近 7 日複習正確率)
- 首次使用(或本版本首次升級)提供**可跳過**的 15 分鐘分級測試:短聽力+3 題、短閱讀+3 題、3 句跟讀、50 詞寫作 → 五維初始分;跳過則全部 50。
- 「今日」頁加小型五維雷達圖(不佔首屏主位)。

## 任務 3.2 動態任務分配 + AI 點評

- 規劃器權重 = 基礎權重 × 弱項加成:最低兩維各 +50% 後歸一化;用戶手動調過則手動值優先。
- 每日收官(任務全完成或跨日結算)呼叫 DeepSeek 出 ≤3 句點評:做得好的一點、最需改的一點、明天重點。輸入僅當日結構化數據(完成率、分數、錯誤摘要),禁止塞原始長文本。

## 任務 3.3 獎懲系統

- 設定頁嚴格度:**溫和 / 硬核**,默認溫和。
- 通用:積分(完成得分,連續打卡乘數)、里程碑成就(7/30/100 天、生詞 500/2000、首次跟讀 90 分等)。
- 溫和:未完成僅記錄 + 次日欠账提示;連續 3 日未達標自動下調 20% 日目標(避免死亡螺旋)。
- 硬核:未完成滾入次日(封頂 +50%,超出丟棄);Web Push 每日提醒(需授權);連續未達標首屏顯示欠账橫幅。
- 禁止:羞辱性文案、無上限加量。懲罰文案語氣=嚴格但支持的教練。

## 任務 3.4 AI 情境對話 + 雅思口語模擬

- 對話:選場景(點餐/面試/機場/自定義)→ DeepSeek 扮演角色 → speechSynthesis 朗讀(TTS 升級後續)→ 用戶語音回答(Provider 轉寫)→ 循環;每輪附「更地道的說法」摺疊區;10 輪或用戶結束後出總結。
- 雅思模擬:內置 Part 1/2/3 題庫(AI 生成,標註「仿真題,非真題」);Part 2 帶 1 分鐘準備 + 2 分鐘作答計時;結束後 DeepSeek 按四維(流利連貫/詞彙/語法/發音——發音分取 Azure)輸出各維 band 分與依據,固定 JSON rubric。
- 對話與模擬計入「說」任務時長與 speaking 能力分。
